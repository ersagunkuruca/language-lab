# Learn

This is a programming language you build by connecting pieces, not by
typing text. Pick where to start. Each one is short, and each one links
on to the next.

---

## Never written a program?

**[For a five-year-old](tutorial.html#part-1-for-a-five-year-old)**

Machines, strings and stickers. What this is, with no programming words at
all. Two minutes.

## You program, but not in Haskell or Lisp

**[For programmers new to functional programming](tutorial.html#part-2-for-programmers-who-havent-done-functional-programming)**

The six ideas the language borrows from that world, in plain words: values
flowing through functions, functions as values, naming, cases, walking the
data instead of looping, and effects written in the type.

## You want to try it with your hands

**[The hands-on guide](guide.html)**

Open the editor next to it and change one small program, the two dice,
step by step. Every section ends with one thing to try.

## You want the whole language

**[The tutorial, part 3](tutorial.html#part-3-the-language)**

One idea at a time: the program as a tree, holes, data and `match`, loops
as folds, effects, running a function backwards, calculus. Each idea is
shown in the editor.

For every detail, there's [LANGUAGE.md](../language/LANGUAGE.md).
