compare where we are against the other reviews and docs like 'what a good
language needs'." The backlog is down to three rows (I219, P7, P8) after the

## The verdict, first

**The lists are nearly all built.** In two weeks, almost every row the
earlier reviews raised was built, or closed with a measured reason. Of the
17 ranked gaps of "what a good language needs" (ASPECTS b), 16 had a row,
and 15 of those are closed. The one left is the license, which Ersagun
postponed. One more, resources (L192), closed as a design note only, and
one, reviewing a change, never got a row. Of the 10 blind spots with rows,
9 are closed (P8 is the license). Of the 12 foundation findings, 8 are done,
2 partly done and 2 still open. All 8 items of LANGUAGE-NEEDS Part 2 are
built, and so are the outsider read's rewrites. Start-up,
R10's high finding, went from 6.5 s to 0.6 s for a warm `ters check wc`.

**But "the backlog is empty" overstates where we are, in four ways:**

1. **Nothing has checked the whole of main in 16 days.** Of the last 100
   Check main runs, **94 were cancelled, 1 failed, 5 are pending, and none
   passed**. Most recent runs went past the job's 20-minute timeout,
   which GitHub shows as cancelled. I110 is in DONE.md as fixed (#2135), but
   its fix only takes effect once a run finishes, and none has. The
   Nightly has never passed since the split (I208): its one run after it,
   11-12, failed. The `good` tag is still at `796f263` (2026-10-28). Every
   "closed, its example works" since then was checked by covering tests
   and by hand, never by the full suite. This was REVIEW-2026-11-09 §3 and
   REVIEW-2026-11-11 §1, and it has not changed.
2. **The goal rows closed by measurement, not by finishing.** Stable
   references, free lists and multithreading (Ersagun's focus since 11-10)
   closed as C42, C57, C58, C59, C60, C187 and C200, "waiting for an
   example". Ersagun approved that rule, and each one measured under 10%
   on today's examples. That is a fair way to close a row. But it means the
   goals are **built where an example asked, not in general**. Threads on
   compiled JavaScript are not built. Regions are not built. Flat layout
   is not built. Fibers in WebAssembly wait for browsers.
3. **No one outside the project has used Ters.** Every measure in every
   review is against our own 57 examples and 14 bigger-program rounds,
   written by agents through the MCP or the editor. (Mobile is the
   exception: Ersagun has played the dice, pig and tumble APKs on his
   Android phone. Their minor visual issues come from the pages' styles
   assuming a screen width, which is an app issue, not a language one.)
   Nobody has
   read the docs cold since 11-03, and nobody has tried to write a program
   from scratch with only the docs.
4. **Some docs claim more than is true.** SPEC §12 still lists S7 as "NFC
   not built yet" (built, L214a), S8 as "pending" (decided and built,
   L179, L211), and S13 as "bug" (fixed, L178). CONFUSING.md says "each
   open problem is also a row", but 9 of its 10 problems are open with no
   row. Details in §5.

None of this is a crash. The language side is in good shape. What's weak
now is the **net that would tell us if it stopped being in good shape**,
and the absence of anyone but us using it.

## Method

```
# timings (warm = second run, with .lab/ written)
node cli/ters.ts check examples/wc; node cli/ters.ts run examples/wc </dev/null
node cli/ters.ts compile examples/wc -o wc.mjs; node wc.mjs </dev/null
# test reach of a one-line edit
echo '// probe' >> ters/src/lang/text.ts; (cd ters && node test/affected.ts --list); git checkout ters/src/lang/text.ts
# kind tests (FOUNDATIONS' grep)
grep -rhoE '(case "[a-z]+"|kind [!=]== "[a-z]+")' ters/src ters/cli ters/mcp compiler/src editor --include=*.ts | wc -l
# Check main's last 100 runs on main
GET repos/ersagunkuruca/language-lab/actions/workflows/check-main.yml/runs?per_page=100&branch=main  (conclusions counted)
# each row id
grep -n "^| <id> " docs/process/DONE.md
```

Timings are from one container and are only good for comparing with each
other (2026-11-05 rule: relative sizes, never wall-clock promises).
