# Editor click-through QA, 2026-11-13 afternoon

The second pass of the day, over the editor changes since [QA-2026-11-13.md](QA-2026-11-13.md):

- the page panel's Pause, Back, On and "Go on from here" (I239c to I239h, #2584 to #2597);
- a paused page handing back to the compiled one, tested on the site's prebuilt page (I253, #2603);
- the Changes tab compared with a branch, a commit or a pull request on GitHub (E263, #2577).

**Build tested:** `main` at `f992fb8` (#2603), built with `npm run build-editor` in `ters/`. It was served with `python3 -m http.server` from the repository root, so the page reads checks.json and the prebuilt pages as the site does. It ran in headless Chromium (Playwright) at 1400×900.

The container reaches GitHub only through its proxy. So the page's requests to raw.githubusercontent.com and api.github.com were answered by `curl` through a Playwright route, unchanged. The live site couldn't be reached.

## What works

**The Changes tab with GitHub:**
- **A pull request shows its own change.** Bounce against `#2354` lists `kicked` as changed. Its two changed lines show their `was:` lines, and its comment shows as changed too. There is a link to the pull request. The tab says it compares from where the branch left the base (`11a2ff8`) to its newest commit (`f58ecf8`).
- **A commit works.** Bounce against `1411b38a^` gives the same change. Dice against `2d173aae^` (before I197) lists `bar`, `bars`, `landed` and `main`, each with its changed lines and the old type of `landed`.
- **These show "No changes.":** a pull request that doesn't touch the program (`#2599`), one that only changed how files are saved (`#2575`), and `main`.
- **A bad name says what's wrong.** `nosuchbranch` gives "Couldn't compare with nosuchbranch: nosuchbranch has no ters/examples/bounce/code.json (or no such branch, tag or commit). Compared with the example as shipped instead."
- **Timing:** a compare took 2 to 3 s for a commit and 6 s for a pull request, which needs two api.github.com reads.
- **The marks work.** Clicking `bars` in the list opens it with its added and changed nodes marked in the graph: `sum` green, the `most`s amber.
- **Mark reviewed, Stop comparing with git and Forget reviewed** each change what the tab compares with, as their notes say.

**Pause and step:**
- **Dice is quick.** After three Rolls, on the compiled page:
  - Pause took 86 ms.
  - Each Back took about 100 ms, down to "Paused after 0 of 3 events, as far back as the window reaches", with Back disabled there.
  - The slider and On ▶ step as well.
  - "Go on from here" brings back Pause and "Steps back at most 10 s".
  - The page shown at the start is right: "Nothing rolled yet", every count 0 (`dice-stepped-to-start.png`).
- **Bounce goes back and on correctly**, just slowly (Q1). It is paused after 1,482 of 1,482 frames. The slider to the window's start takes 0.5 s. "Go on from here" brings the running page back.
- **No page errors.** The only console errors are 404s (Q3).

## How to repeat

As in [QA-2026-11-09.md](QA-2026-11-09.md), served over http. The scripts:
- open a program and a tab by its label;
- type a revision into `.chg-rev`, press Compare, and wait until "from GitHub…" is gone;
- press Pause, ◀ Back, On ▶ and "Go on from here" by their labels, and time each one by the steps line redrawn after it.

For dice, the page's Roll button is pressed three times inside `iframe.page` first. Screenshots are in [screenshots/2026-11-13b](screenshots/2026-11-13b/).
