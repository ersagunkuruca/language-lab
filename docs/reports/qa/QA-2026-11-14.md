## How to repeat

Build in `ters/` with `npm run build-editor`, and serve the repository root with `python3 -m http.server 8765`. Then, in Playwright:

- click each `[data-set="program"]`, then each `[data-def]`, and listen for `console` errors and `pageerror`;
- time a click by when `page.evaluate(() => 1)` returns after it, since a busy page answers only when it is free;
- for the Changes tab, type into `.chg-rev`, press Compare, and wait until "from GitHub…" is gone.
