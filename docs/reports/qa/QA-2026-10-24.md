# Editor click-through QA, 2026-10-24

The daily point-and-click pass. It follows [QA-2026-10-23b.md](QA-2026-10-23b.md) (QA3, the evening pass), and about 25 editor PRs have landed since then (#283 to #338): the minimap fix, touch Pick, keyboard menus, one pane at a time on narrow or low screens, pinch zoom, arithmetic in the palette, Run main in a worker with Stop, named folded boxes, a sharper CPU picture, and the guitar pedal as a page that plays sound.

**Build tested:** `main` at `39a2164` (#338), built with `npm run build-editor` and opened from disk (`file://…/index.html`) in headless Chromium through playwright-core. The live page wasn't tested, because this container can't reach ersagunkuruca.github.io. There is no GPU here, so the shader pictures ran on the CPU fallback. The pedal's sound was triggered but not listened to.

Screenshots are in [qa/2026-10-24/](screenshots/2026-10-24/).

## What works

- **Every example runs.** All 14 programs and all 152 definitions were opened. Every `main` ran with the expected output. No page error or console error came up, apart from Chromium's own "Failed to create WebGPU Context Provider" warning, which is expected without a GPU. `SWEEP=all npm run smoke` passes (152 definitions, plus 16 on programs saved by an older editor). No definition opens in a warning or error state, and every program except the two shader ones opens on `main`.
- **A long run no longer freezes the page** (#294). Countdown's `main` shows "Running…" with a Stop button, and the longest gap between frames was 67 ms (it was 9,997 ms). Stop ends it ("(no output) Stopped.").
- **Keyboard** (#287). Enter on a literal, then typing and Enter, commits the value and puts focus back in the program, so the next Tab moves on. Enter on a call opens its menu on "Change the function…". Shift+F10 and the Menu key open the same menu as a right-click, and Escape puts focus back in the program.
- **Typed arithmetic** (#292). In `double(x)` the palette offers `x * 2`, `2 * x`, `x + 1` and `x * x - 1` as values, and `x * 2` fills as `x · 2`.
- **The can't-edit list is down to almost nothing.** Change the function keeps the inputs: in `fall`, `drift + drop` became `drift − drop`. The palette offered only what keeps `distance` in metres, so multiply wasn't on the list. A used input can be removed: removing `speed` from `fall` leaves a hole where it was used and drops its argument from the call. Both undo.
- **The minimap** (#283) draws in the page's colours. On a first visit, Numbers & physics `main` opens with its first steps at the left edge (#300), and the zoom button reads the real zoom, 60% (`first-visit-1280x720.png`).
- **Folding** (#295). A folded box names what it holds ("trace, with fuel") (`folded.png`). After folding an inner frame, dragging its box ("Moved 4 nodes") and clicking a fold toggle, no nodes overlapped. That last click didn't unfold the dragged box itself, though, so the QA3 L1 case of unfolding a box after dragging it wasn't re-run end to end.
- **The CPU picture** (#296) is 64×64 at about 18 ms a frame, with a one-line status ("Click it to pause and sharpen"). The ray marcher's credits are right above it (`raymarch-cpu.png`).
- **Pages.** The dice page says "Rolls: 1" after a roll and keeps its state after switching to another program and back (#298) (`dice.png`). In the guitar pedal page (`pedal.png`), A strum, Driven/Clean and Harder all respond (drive 32 → 64), and Stop sound works, with no errors.
- **Phone and tablet.** At 390×844, 844×390 and 768×1024 the page is one screen with no scroll, one pane at a time (#277, #288) (`phone-390.png`, `phone-landscape.png`, `tablet-768.png`). Undo comes first in the top bar (#291). The hints speak of long-press, Pick and pinch. With CDP touch events, long-press → Pick on three nodes picks all three and the menu offers "Tidy the 3 picked" (#285). A two-finger pinch zooms the graph (#290), from 60% up to the 300% cap.

## How to repeat

`npm run build-editor`, then playwright-core with `executablePath: "/opt/pw-browsers/chromium"` on `file://…/index.html`, as in [QA-2026-10-23.md](QA-2026-10-23.md) and [QA-2026-10-23b.md](QA-2026-10-23b.md). New this time:

- **Pages** mount in the Run panel. `page.frameLocator(".side iframe").first()` reaches their buttons, even though `.side iframe` counts 0 from the outer page.
- **The graph's world** is `.p-graph svg.canvas > g.world`. Use `.first()`, because the minimap has a copy.
- **Frame gaps:** a `requestAnimationFrame` loop that records gaps, read after the run, shows whether a run blocks the page.
- **Pinch:** CDP `Input.dispatchTouchEvent` with two `touchPoints` moving apart.
