# Editor click-through QA, 2026-10-31

The daily point-and-click pass (QA11). It follows [QA-2026-10-30.md](QA-2026-10-30.md) (QA10). 22 editor PRs landed since then, #662 to #703. Five of them fixed QA10's findings (#662, #663, #665, #666, and the freeze behind the smoke's failure). The others added:

- **Page restyles:** Two dice, Pig, the guitar pedal and the to-do outline each use one style sheet, with no inline styles (#668, #671 to #673).
- **Named results:**
  - a definition declares its results, and a use is written from the palette (#698);
  - the graph gives one output per named result (#677).
- **Run:**
  - a solve shows its mode, how many answers, and whether it ends (#699);
  - a Fixed reads as its number (#693);
  - a function input takes a definition's name (#703).
- **Smaller changes:**
  - a data type's panel says how `main` stores it (#700);
  - embeds were tidied (#664, #695);
  - the editor has its own icon (#696).

The docs moved into one tree (184903c), so this report and its screenshots are under `docs/reports/qa/`.

**Build tested:** `main` at `8eb05ab` (#707), built with `npm run build-editor` and opened from disk in headless Chromium (playwright-core). The live page couldn't be reached from this container. There's no GPU here, so the shader pictures ran on the CPU fallback. The full browser smoke wasn't run, following Ersagun's note of 2026-10-29. Each item below was checked on its own instead.

## What works

- **Every example runs.** All 19 programs were opened, with every definition. Every text `main` ran with its expected output. No page or console error came up, apart from Chromium's "Failed to create WebGPU Context Provider" warning, which is expected without a GPU. The only warnings on opening are the two in M1.
- **A page gets room** (#666). Tumble's frame is 536 px wide, up from 306, and the first board is in view under the buttons (`tumble.png`).
- **The restyled pages.** The pedal reads as a stompbox, with DRIVEN, Softer, drive 32 and Harder over its curve (`pedal.png`). The to-do outline has round ticks and small ↑ + × buttons (`todo.png`).
- **Countdown's `solutions`** opens with its answers, `[apply(times, apply(plus, number(3), …`, not `[]` (#663).
- **The ray marcher's `trace`** lists its inputs as `x`, `y` and `time` (#662).
- **`polar` declares its results:** `polar : (Float64, Float64) -[Choice]-> x: Float64, y: Float64` (`polar-results.png`).
