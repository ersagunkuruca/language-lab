# Editor click-through QA, 2026-11-14 (afternoon)

A second pass today, after E264 (#2680) and E264b (#2686). It follows [QA-2026-11-14.md](QA-2026-11-14.md). Those two PRs changed how the editor treats `+` and `·` rows:

- A `+` or `·` row is its left-nested pairs.
- An item added anywhere keeps the row left-nested.
- For a Float64 row, only the innermost pair's two may swap (a + b is b + a). Any other move would regroup, which changes how a Float64 rounds, so it is refused.
- `++`, `and` and `or` rows move as before.

**Build tested:** `main` at `97da43f` (#2686), built with `npm run build-editor` in `ters/`, served with `python3 -m http.server` from the repo root, and opened in headless Chromium (playwright-core). There's no GPU here. The full browser smoke wasn't run, following Ersagun's note of 2026-10-29.

Screenshots are in [screenshots/2026-11-14b/](screenshots/2026-11-14b/).

## Findings

| # | Finding | Repro | Severity |
|---|---|---|---|
| L1 | **Later on a Float64 row's second item looks available, but is refused on click.** In `0.5 · gravity · (time · time)`, `gravity`'s Later button is enabled and titled "Swap it with the one after". Clicking it gives the orange "Refused: the order of a product changes how a Float64 rounds". The first item's Earlier, by contrast, is greyed out with "Can't: it's first already". A move that E264 always refuses could be greyed out the same way, with its reason as the title. The graph's drop onto a port that would regroup could say why before the drop, too. | Numbers & physics → `fall` → click `gravity` in the blocks → Later. | Low |
| L2 | **The Refused note stays on the status line after the next selection.** After a refused Later, selecting another item and undoing an earlier move still shows the orange "Refused: …" line (`fall-product-selected.png`). The next selection could clear it, as other notes are cleared. | As L1, then click `0.5`. | Low |

Not checked this time:

- an Int `+` row of three or more. No example has one, so whether Int rows still move freely, as exact sums could, is untested here;
- `or` rows;
- the graph's drop onto a port that would regroup a Float64 row.

## How to repeat

As in [QA-2026-11-09.md](QA-2026-11-09.md). The program list now fills in a second or two after the page loads, so a script should wait for `[data-set=program]` first. For the panel gestures, click the item's `span.x` in `.p-text`, then the `.side` button by its text.
