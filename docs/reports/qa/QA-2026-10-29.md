# Editor click-through QA, 2026-10-29

The daily point-and-click pass (QA9). It follows [QA-2026-10-28.md](QA-2026-10-28.md) (QA8). 10 editor PRs landed since then, #562 to #579. Eight of them fixed QA8's findings. The other two:

- renamed Wrap in… to Insert a node after it… in the graph (#564)
- added a new example, Lockstep: a cart on a spring, written in Fixed (#568, #579)

**Build tested:** `main` at `1edcdac` (#579), built with `npm run build-editor` and opened from disk in headless Chromium (playwright-core). The live page couldn't be reached from this container. There's no GPU here, so the shader pictures ran on the CPU fallback.

Screenshots are in [qa/2026-10-29/](screenshots/2026-10-29/).

## What works

- **Every example runs.** All 16 programs and 160 definitions were opened, and every `main` ran with its expected output. The new Lockstep `main` is a value, and Show values gives "position -0.3446562376, velocity -0.7330740627, steps -1480287269" (`lockstep.png`). No page or console error came up, apart from Chromium's "Failed to create WebGPU Context Provider" warning, which is expected without a GPU. `SWEEP=all npm run smoke` fails on one check, twice in a row: see H2.
- **Add a step before this** (#563). On a `main` step it reads "Added a step before it: fill the hole with what to do there." Filled with `print("hello")`, it's a plain `print("hello")` line, and Run main prints `hello` first (`add-step-before.png`).
- **Escape after Replace with…** (#567) gives "Cancelled: what was there is back.", and `√(length / gravity)` returns.
- **Search by meaning** (#569). On a Float64 hole, "square root" offers `sqrt(□)` (described as "elsewhere called square root"), "absolute value" offers `abs`, and "round down" offers `floor`.
- **Insert a node after it…** with `abs` gives `abs(√(length / gravity))`.
- **Make it a function** names inputs plainly (#574): `part = (speed, time) => speed · time`.
- **Implementations** keep the type's spelling (#576): `size at Float64`, "one hole for its operation, operation". An interface has its own mark, `◇ Size` (`implement.png`).
- **Opening Countdown's `solutions`** no longer hangs the page (#562): it opens in 1.0 s, with a longest frame gap of 0.95 s (it was 19.9 s).
