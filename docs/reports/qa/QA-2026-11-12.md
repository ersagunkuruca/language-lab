A short pass. It follows [QA-2026-11-11.md](QA-2026-11-11.md), which another thread wrote on the evening of 11-11. Since then, two PRs touched the editor, and both added examples:

**Build tested:** `main` at `71ae27a` (#2434), built with `npm run build-editor` in `ters/`, served with `python3 -m http.server` from the repo root, and opened in headless Chromium (playwright-core). Only the two new examples were walked. The other programs were walked on 11-11.

## What works

- **pond opens and runs.** Every one of its 105 definitions opens in under 0.8 s. Run main with `30 100` prints "Checks: 0 outside the pond, 0 spent, 0 overfull patches, 0 too old", with its credits.
- **Markov chains runs.** Run main takes 0.19 s, compiled. It prints the weather chain's settled distribution, 0.521739 0.304348 0.173913, and the two rooms' 0.6 0.4. For the chain that only swaps, it prints "no answer".
- **No page errors.** The console showed the usual 404 for a missing resource.
