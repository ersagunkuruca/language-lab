# Editor click-through QA, 2026-10-26

The daily point-and-click pass, run late: the 25th's run didn't happen, so this one covers both days. It follows [QA-2026-10-24b.md](QA-2026-10-24b.md) (QA5). About 40 editor PRs landed since then, #376 to #438. The biggest change is how parts are taken apart and put back. Delete now leaves what fed a node **loose** (#433). A value added on the canvas starts loose (#436). A drop on a filled input swaps the value in (#434). An empty input is a hollow port, not a hole node (#435). Lists and chains gain items in place (#418, #432), and definitions can be duplicated (#417). Smaller changes: Replace with… (#414), menus that say what they do (#416), the hidden map (#426), and the phone top bar with More (#427).

**Build tested:** `main` at `33f44f0` (#438), built with `npm run build-editor` and opened from disk in headless Chromium (playwright-core). The live page couldn't be reached from this container. There is no GPU here, so the shader pictures ran on the CPU fallback.

Screenshots are in [qa/2026-10-26/](screenshots/2026-10-26/).

## What works

- **Every example runs.** All 14 programs and 148 definitions were opened, and every `main` ran with its expected output. Nothing opens in a warning state. No page or console error came up, apart from Chromium's own "Failed to create WebGPU Context Provider" warning, which is expected without a GPU. `SWEEP=all npm run smoke` passes: 148 definitions, plus 16 on programs saved by an older editor.
- **Delete keeps what fed the node** (#433). Deleting `√` in `period` leaves a hole in its place, and `length / gravity` stays loose under a dashed frame "loose, not used yet". The status says what happened, and Undo brings it all back (`delete-leaves-loose.png`). Wiring the loose frame's right-hand dot onto the hollow port puts it back: "Wired it in: it's part of the definition again." Values then update.
- **Loose values on the canvas** (#436). Add a value here… makes a loose hole. Typed `42`, `"hi"` or `sqrt(2)` fills it. Dragging its frame's dot onto `main`'s hole gives `main() = 42` (`loose-sqrt.png`).
- **Change the function and remove a used input** still work. The palette for Change the function offers only what keeps the units: in `drift = speed · time`, `subtract` isn't offered, because metres per second minus seconds doesn't type.
- **Duplicate a definition** (#417): "Duplicated period as period copy". The copy sits next to the original.
- **The palette reads what the blocks print** (#388, #390, #395). `x < 1`, `-x`, `x + 1/2`, `sqrt(x) * 2`, `"a" ++ "b"`, `as fraction(3)`, `show fraction(ratio(1, 2))` and `ratio(1, 2) + 1` are all offered as values. `add` and `subtract` say "where a is a number type" (#423).
- **Fractions read as fractions.** `print(show(ratio(1, 2) + ratio(1, 3)))` prints `5/6`. On `fraction(1, 2) + fraction(1, 3)`, Run explains what to do about the Choice effect, and Show values gives "Its first answer: 5/6" (#400).
- **The Blocks pane** draws what the blocks text prints (#384). Queens `main` reads `first(queens(8), else nil)` and `count(queens(8))`, and the ray marcher's `shade` reads `normal.y` and `p.y`. Right-click in Blocks opens the part's menu with descriptions. Clicking an operator selects its call (#387).
- **Navigation.** Opening the guitar pedal shows its open `main` in the navigator (#424). The status bar reports typing in a page field: "Typed 100 in “°C” on the page." (#425). The map starts hidden where it would cover nodes (#426) (`first-visit-1280x800.png`).
- **Phone and tablet.** At 390×844, 844×390 and 768×1024 the page fits with no scroll and the top bar doesn't overflow. At 390 px, Learn, Credits and Cells sit behind More (#427) (`phone-390.png`). "+ New definition" switches to the pane with its form, and tapping a □ in Text switches to the palette (#380).
- **Learn** opens the hands-on guide as a page, `guide.html` (#406).

## How to repeat

As in [QA-2026-10-24.md](QA-2026-10-24.md). New this time:

- **The graph's world** is `.p-graph svg.canvas > g.world`. A loose part's frame holds a group with class `faded`. Its own output is `circle.outp` inside `faded`, and the frame's end dot is the rightmost `circle.outp` outside it.
- **An empty input** is `circle.inp.empty`.
- **Add a value here…** opens a pop-up palette with focus in its search, so type with `page.keyboard` rather than filling the side panel's search.
