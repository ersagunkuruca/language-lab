## What works

- **Choices (E292).**
  - The tab fills in after a few seconds while the page keeps drawing. It took 0.5 to 1.4 s for calc, 1.9 s for moths, 3.3 s for flock, and 4.0 s each for pond and Night watch.
  - Night watch shows 17 rows: Set as a hash table, two placements, and 14 schedule entries.
  - Copied maps show as one row with a count (`tick's map ×2`).
  - Hovering a row shows the facts the pick read.
- **Badges.**
  - calc's `tokens` has its keep placement as a fork on the `(t) =>` frame in the graph and after `(t) => not (t = gap)` in Blocks.
  - Clicking either badge opens Choices with the row marked (`choice-badge-graph.png`, `choice-badge-blocks.png`).
- **Holding.**
  - Clicking "sorted list" on Night watch's Set holds it ("Held Set as sorted list"). The row reads Held and says "Compiler would pick hash table".
  - Clicking Held lets the type go back to the compiler's pick.
  - Holding numbers' Nat as binary is refused, with the reason (see L280c).
- **Run's warm-up (I320).**
  - calc's Run 1 s after opening the program takes 0.4 to 0.5 s.
  - Pressed within the first half second it takes 0.9 to 1.7 s. That time is calc's own check in the worker.
  - Warming the worker as soon as a program opens, rather than 0.3 s later, made no difference (1.4 to 1.7 s at 0.3 s), so it isn't kept.
- **Phone.** Choices fits at 390 px with no sideways scroll (`phone-choices.png`).
- **No page errors** came up in the whole pass.

## Findings

| # | Finding | Repro | Severity |
|---|---|---|---|
| M1 | **Choices says "None" for a program with type errors.** The worker gives no entries when the check has errors, so the tab reads as if the compiler had nothing to choose. It should say the choices wait on the errors, as Run does. | Any program → break a definition → Choices | Medium |
| M2 | **Choices are worked out again after every edit, even with the tab closed.** The badges need them, so each edit asks a worker for the whole program's choices: 3 to 5 s of CPU for page programs (pond 4.1 s, Night watch 4.0 s). This runs beside Run's worker and the page's compile. The ask could wait until edits settle, and be skipped when neither the tab nor any badge would change. | Night watch → edit any number five times | Medium |
| L1 | **Schedule rows name the compiler's own definitions and split one walk into several rows.** Night watch's Schedule reads `flock over over flat map's flock over walk, its list made by lets`, followed by the same walk `made by map` and `made by a call`. The names come from fuse-walks.ts's made definitions. A row per walk in the program's own definitions, with its written name, would read better (`schedule-rows.png`). | Night watch → Choices → Schedule | Low |
| L2 | **The side panel's tabs wrap to two lines at 1400 px.** With Choices there are seven tabs: Definition, Program, Checks, Choices, Files on the first line, Changes and Guide on the second (`side-tabs-wrap.png`). | Any program, window 1400 px wide | Low |
| L3 | **A mode plan's pick shows its goals by their drawn text.** calc's `inverse` row reads `relational, goals a function(…)`. | calc → Choices → Algorithm | Low |
| L4 | **On a phone, a row's count wraps onto a line of its own** under a long name that wraps (`nibbled's bites walk, its list made by lets` then `×3`). | iPhone → Night watch → Choices | Low |
