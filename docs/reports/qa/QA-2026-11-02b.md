# Editor click-through QA, 2026-11-02b

QA15. It follows [QA-2026-11-02.md](QA-2026-11-02.md) (QA14). It was started to refill the Editor lane, and it looks at what bigger-program round 8 (board, [GAPS.md](../GAPS.md#round-8-board-a-page-written-in-the-editor-2026-11-02)) changed in the editor, #1043 to #1061:

- **Typed operators:** `>`, `≥`, `≤` take the generic compares (E185, #1043); `≠` and `!=` read as `not(a = b)` (E191, #1055).
- **Which meaning a typed name takes:** a field several types share offers each type's reading (E186, #1047; E186b closed with a test, #1060); a value definition named inside a list or a call (E187, #1044); own case names, `random()`, `unit` (E188, #1052).
- **A fresh match** keeps one hole per case after the first is filled (E189, #1049).
- **Typed steps:** `a; b` and a step before a one-action body (E190, #1053).
- **`1500.0`** typed is a Float64 and prints with its point (E192, #1057).
- **A picture is lowered once per version of the code** (C90's editor half, #1061).

**Build tested:** `main` at `37854f2` (#1061), built with `npm run build-editor` and opened from disk in headless Chromium (playwright-core), since the live page can't be reached from here. There's no GPU, so the shaders ran on the CPU fallback. To find when the ray marcher got slow, `1cb77ae` (QA14's build), `7c0ac36` (#1037) and its parent were built too. Following Ersagun's note of 2026-10-29, the full smoke wasn't run.

Screenshots are in [screenshots/2026-11-02b/](screenshots/2026-11-02b/).

## What works

- **Every example's `main`, and every definition.** All 22 programs were opened, every definition of each, with no page or console error. Every text `main` printed what it should (physics, sort, queens, Countdown's solutions, calculus, Run backwards, conjugation, relations, effects, Lockstep). The page programs drew their pages, and the three shaders drew on the CPU. The side panels' "No values on the wires" lines all give a reason in plain words ("it runs longer than the 200 ms the graph waits", or Tumble's `a move`: "no answer (a Choice with none)").
- **E185.** `length(w) > 1` fills, `long : (List a) -> Bool`. `length(w) ≥ 2 and length(w) <= 9` reads back as `… ≤ 9`. `a < b and b ≤ c` gives `where a is a Number with <`.
- **E186.** With data types `Card(title, points)` and `Quick(title)`, typing `q.title` in a new `heading(q)` lists "More than one type has these fields, and nothing here says which: pick one", then `q.title as a Card` and `q.title as a Quick` (`e186-choices.png`). Picking Quick gives `heading : (Quick) -> Text`.
- **E187.** With `styles = "bold"`, `[styles, styles]` fills as `List Text` and `some(styles)` as `Optional Text`.
- **E188.** In a program with its own `Stage = todo | doing | done`, `[todo, doing, done]` fills as `List Stage`. `random() · n` gives `(Float64) -[Random]-> Float64`. Typing `random` lists `random` first; typing `unit` lists `unit Unit` first, and Enter fills `nothing = unit`.
- **E189.** *match s · Stage* reads three cases, each `□`. Filling the middle case's hole first keeps the other two holes, and they fill in turn.
- **E190.** `print("a"); print("b"); print("c")` in `main` reads as three steps, in Blocks, Steps and Nested. A function `(x) => print(x)` offers *Add a step before this…* on its `print`.
- **E191.** `a ≠ b` gives `differ : (a, a) -> Bool`; `a != b + 1` reads too. `xs.head <> b` is refused with "after .head, “<> b” isn't read: no operator starts it".
- **E192.** `1500.0` gives `big : Float64` and prints `1500.0`. `x + 1.0` gives `(Float64) -> Float64`, `1e3` gives `Float64` `1000.0`. Inside a list it doesn't hold (F3).
- **C90.** Opening the ray marcher the second time took 2.2 s, against 10.3 s the first time. The Mandelbrot set: 1.7 s, then 0.5 s.
- **QA14's I134 and I135 hold fixed.** Alt+↑ from `"doing"` in a case body selects the match. In Constructions, a key in the palette now costs 64 to 99 ms (was 99 to 182 ms), after a first key of about 200 ms. *+ New definition* opens its form in under 0.1 s.

## How to repeat

As in [QA-2026-11-02.md](QA-2026-11-02.md). New this time:

- **The driver:** the round 8 driver (`drv.ts` and `lib.ts` in the project's `gaps-round8/` files) keeps the editor's localStorage in a `state.json` between scripts, so one script can build a program and the next can probe it. `t.def`, `t.fill`, `t.pick` and `types().type` write a new program the way a person would.
- **Frame gaps:** record `requestAnimationFrame` gaps over 100 ms from the page (a small loop on `window`), then open a definition and read them. A CPU picture that runs back to back shows as a steady gap near its frame time.
- **Which commit:** `git worktree add <dir> <sha>`, link `ters/node_modules` into it, `npm run build-editor` there, and point the driver at that `index.html`.
- **Undo's landing:** after Undo, read `.nav-row[data-def].on` and the text pane; nothing marked means the view didn't go back.
