## What works

- **All 46 programs open, with all 1,983 of their definitions drawn, and every text `main` runs.** There were no page errors. The console showed only Chromium's "No available adapters" warning.
- **Times:** in the full walk some definitions took 1–5 s to draw, because the pages opened before them keep running. Alone, every program's slowest definition took under 0.7 s, except rain's (see L2).
- **The rain page** (`rain-wiped.png`):
  - "Page: rain, drops on the greenhouse glass" sits after flock in the picker.
  - Its 43 definitions draw, and the page runs.
  - Dragging across the glass wipes the drops away, and new ones run in from the top.
- **An else if chain is flat** (`else-if-flat.png`):
  - In Blocks and in the text, each `else` of machine's `simplified` sits at the first `if`'s indent, with one row per test. Measured in the pane, every `if`/`else` keyword is at the same x, and every `then` is 25 px further right.
  - algebra's `simplify` and folders' `key` read the same way. In algebra, `first(x, else if …)` reads as a chain, since `else` is first's own word for its second argument.
- **machine after I386:**
  - Its 141 definitions draw. Main runs primes.asm in 0.64 s: 82,280 steps as written, 72,284 optimized.
  - Its deepest definition now is `paired`, whose matches are nested because they really are nested.

## Findings

| # | Finding | Repro | Severity |
|---|---|---|---|
| M1 | **chomsky isn't in the picker.** Like the rain page before #3537, #3543 added the example without an `editor/examples.json` entry. Its `main` takes a length argument, so the entry needs `"run": { "args": ["6"], "names": ["length"] }` too, or the Run panel has no Run main button. With that entry, built locally, all 94 of chomsky's definitions draw and Run main prints the seven grammars, with their levels, words and machines (`chomsky-run.png`). | Look for chomsky under Programs. | Medium |
| L1 | **An if inside a match row stays on one line however long it is.** In machine's `paired`, the `load(into, a₂) →` row holds a 154-character if, `if b = a₂ and not ‹is register arg›(a, into) then cons(…) else cons(…)`. The text view prints it on one line of 198 characters, where an if wider than the 80-column width would go one branch per line anywhere else. | Print machine's `paired` in the text view, or open it in Blocks. | Low |
| L2 | **The rain page's definitions draw slowest of all.** Alone, its slowest definition (`apart`) takes 0.99 s, and `▤ Drop` 1.16 s in the full walk. Every other program's slowest is under 0.7 s alone. | Open rain, then click `apart`. | Low |
| L3 | **chomsky's text names the wrong count, and its output says "way(s)".** main's comment says "four grammars, one at each level of the hierarchy", but the program builds seven, as its README says. The output reads "at most 1 way(s) through a word". This is the example's own text, so it's for the Language lane. | Open chomsky's `main`, then Run main. | Low |
