# Editor click-through QA, 2026-10-23 (evening)

The third point-and-click pass, run the same evening as [QA-2026-10-23.md](QA-2026-10-23.md) because a large batch of editor changes landed since: keyboard editing (#251), program comments (#253), tidy that cuts crossings (#256), wires that bend round nodes (#263), the minimap (#270), the ray marcher's CPU fallback in WebAssembly (#272), collapsible frames (#275), the phone layout (#277) and touch stand-ins (#278). The morning report's findings were all fixed in between (E1 to E14, E22 to E33).

**Build tested:** `main` at `8e3b6ce` (#278), built with `npm run build-editor` and opened from disk (`file://…/index.html`) in headless Chromium through playwright-core. **The live page wasn't tested:** this container can't reach ersagunkuruca.github.io (the proxy refuses it), so the local build of the same commit stood in for it. There is no GPU here, so the shader pictures ran on the CPU fallback, which is what #272 changed.

Screenshots are in [qa/2026-10-23b/](screenshots/2026-10-23b/).

## What works

- **Every example runs.** All 13 programs and all 136 definitions were opened. Every `main` and every action ran with the output you'd expect, and no page error or console error came up in any run. The only console message was Chromium's "No available adapters" warning, which is expected without a GPU. `SWEEP=all npm run smoke` passes (130 definitions, plus 16 on programs saved by an older editor).
- **No definition opens in the orange warning state any more.** The morning report counted 79 of 102.
- **#248 lists in blocks.** No definition shows a list literal as `cons(…, nil)`. What `cons` remains is a pattern (`cons(head, tail) with tail′ →`) or a cons onto a variable (`cons(x, cons(head, tail))`), which is right.
- **#253 program comments.** The Program tab shows each example's comment with links as links, and the comment box under it edits it ("The program's comment is saved."). Ctrl+Z brings the old one back. Above a picture the same comment shows, so the ray marcher credits Hart, Quilez, Enzyme and Wasmtime fuel right above it (`raymarch-cpu.png`).
- **#272 CPU fallback.** Without a GPU, both shader pictures draw and animate (two frames 1.5 s apart differ). The ray marcher reports "WebAssembly on the CPU in 32-bit floats, 51×51, 18 ms a frame". Ripples report 130×130 at 19 ms. Opening other definitions doesn't stop the picture.
- **#221 the dice page survives redraws.** After opening five other definitions, Roll still works ("You rolled 2 and 1: 3.", histogram updated) (`dice-after-switching.png`). It also works after switching to another program and back, though the page starts again from no rolls (see L5).
- **#251 keyboard.** Tab from the status bar lands in the program; Tab and Shift+Tab step through the parts in reading order. Enter on a literal opens its value; Delete clears to a hole; Enter on the hole focuses the palette; typing `2` and Enter fills it and focus comes back, so Tab carries on. Escape deselects. Ctrl+Z undoes. Past the last part, Tab moves on to the Run inputs as it should.
- **#275 folding frames.** ▾ folds a frame into a box that says how many nodes it holds, with wires in on its left and out on its right (`folded.png`). ▸ unfolds it. Fold survives a reload, Undo undoes it, and dragging the box moves what it holds ("Moved 3 nodes"). The right-click menu offers Fold and Unfold too.
- **#277 phone width.** At 390×844 the page is exactly one screen (no scroll either way). The bar at the bottom switches between Programs, Graph, Text and Run. Picking a definition jumps to Graph. Run works there, the shader picture and the dice page work there, and Roll works by tap.
- **#278 touch.** A long press on a node opens its menu; a long press on empty space offers "Add a value here…". Holding and then moving pans instead of opening the menu. A plain tap selects.
- **Writing a program from nothing, gestures only:** + New program → `print` → `"hello"` → Run prints `hello`. + New definition `double(x)` → `*` → `x` → `2` gives `double : (Number) -> Number`. Renaming it `twice` works, and renaming it `main` is refused with a reason. `main` → `print(show(twice(21)))` runs and prints 42. Show inline works. Save file → Delete → Open file gives the program back, and it still prints 42.
- **Navigator search** finds `polar` in both Numbers & physics and Relations in programs.

## How to repeat

`npm run build-editor`, then playwright-core with `executablePath: "/opt/pw-browsers/chromium"` on `file://…/index.html`, as in the earlier reports (selectors are listed at the end of [QA-2026-10-23.md](QA-2026-10-23.md)). New this time:

- **Phone:** `newContext({ viewport: { width: 390, height: 844 }, hasTouch: true, isMobile: true })`; panes are `.panes [data-pane=nav|graph|text|side]`, and the shown one is `main.grid[data-pane]`.
- **Long press:** Playwright has no long press, so use a CDP session: `Input.dispatchTouchEvent` with `touchStart` at the point, wait 700 ms, then `touchEnd`. Picked nodes have the class `.picked`.
- **Folding:** the toggles are `.p-graph [data-fold]` (▾ / ▸), and a folded box is `rect.folded`.
- **Minimap:** `svg.minimap`, with `<use href="#world-N">` inside.
- **Page freeze:** count `requestAnimationFrame` gaps while a run is going.
