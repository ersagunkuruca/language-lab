# lockstep-text

The lockstep example as it was before it became a page (L261a,
EXAMPLES-TRIAGE-2026-11-14): the same cart on a spring in Fixed, with a
`main` that is one Text. It is a test program, not in the editor's picker.
The tests use it as the example of a `main` that is a value, printed the
same by `ters run`, `ters compile`, `ters wasi` and `ters native`, and for
the Blocks' bracketed take-apart (I283). The page is `examples/lockstep`.
