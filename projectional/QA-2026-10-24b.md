## What works

- **Every example runs.** All 14 programs and all 148 definitions were opened, and every `main` ran with the expected output. No page error or console error came up, apart from Chromium's "No available adapters" warning without a GPU. `SWEEP=all npm run smoke` passes (148 definitions, plus 16 on programs saved by an older editor). All four text views (Blocks, Steps, Nested, Lisp) draw for the definition each program opens on, in under 0.6 s each.
- **The pedal** (#333, #335). The page is styled now (#356). A strum, Driven/Clean, Softer and Harder respond, and Stop sound and program switching work. `node editor/sound-smoke.ts` passes all five checks: the recording comes out driven, Clean reaches the audio thread, another program silences the page, coming back plays again, and Stop sound stops it.
- **Pages.** Each page's `main` says "main is the page above" instead of printing its Html (#351). Dice says "Rolls: 0" before a roll (#361). After a roll the status bar says "Clicked “Roll” on the page." (#362). In the unit converter, typing 100 in °C gives 212 °F and 373.15 K.
- **The palette reads typed calls** (#365). `sqrt(x + 1)` fills as `√(x + 1)` in one step and one undo. So do `abs(x)`, `show(x + 1)`, `sqrt(sqrt(x))`, `negate(x)`, `x + y · 2`, `x - 1`, `larger(1, 2)` and `2 + 3`. Each fill takes about 0.1 s, and the palette opens in about 40 ms.
- **The generic + − · <** (#348, #350). The palette offers one `add`, `subtract` and so on, typed `(a, a) -> a`. They work on fractions: `ratio(1, 2) + ratio(1, 3)` runs to `ratio(5, 6)` and `ratio(1, 2) · ratio(3, 1)` to `ratio(3, 2)`. They also refuse text: `"a" + "b"` and `add("a", "b")` aren't offered.
- **Change the function is one undo** (#357). In `fall`, `drift + drop` became `drift − drop`, and a single Undo brings back `+`.
- **Phone and tablet** (#353, #364). At 390×844, 844×390 and 768×1024 the page is one screen with no scroll. The map is off by default on a phone. In landscape the graph gets 275 of 390 px (QA4 measured 210), and the top bar fits, with names and notation each on one cycling button.
- **The new graph drawings** (#366 to #368). In Eight queens `main`, the actions handed to `first`, `count` and `all` are frames titled "action" (`queens-main.png`).

## How to repeat

`npm run build-editor`, then playwright-core with `executablePath: "/opt/pw-browsers/chromium"` on `file://…/index.html`, as in the earlier QA reports. `CHROMIUM=/opt/pw-browsers/chromium SWEEP=all npm run smoke` and `CHROMIUM=/opt/pw-browsers/chromium node editor/sound-smoke.ts` cover the sweep and the sound. New this time:

- **The palette:** click `.blocks-wrap .hole`, fill `#f-query`, and pick from the visible `.opt` buttons. A typed call is the row whose text ends "this, written out".
- **The New definition form:** `[data-act="new-def"]`, then `#f-def-name`, `#f-def-inputs` and the Create button.
- **One-pane layouts:** `.panes [data-pane]` switches panes. `isVisible()` on `#f-query` shows whether the palette is on screen.
- **The text the Blocks pane shows** is `.blocks-wrap`'s `innerText`, not `renderBlocks`'s output (H1).
- **Don't click a page's sound buttons a second time through Playwright** after switching programs. Playwright pauses an AudioWorklet's start (see `editor/sound-smoke.ts`), and the click waits forever. The sound smoke uses the DevTools protocol for this reason.
