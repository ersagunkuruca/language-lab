## What works

- **Every example runs.** All 15 programs and 152 definitions were opened, and every `main` ran with its expected output. The new Shader: Mandelbrot set draws on the CPU fallback (113×113, about 19 ms a frame), with its credits above it (`mandelbrot.png`). No page or console error came up, apart from Chromium's "Failed to create WebGPU Context Provider" warning, which is expected without a GPU. `SWEEP=all npm run smoke` passes (152 definitions, plus 16 on programs saved by an older editor).
- **Loose parts work end to end.** Delete `√` in `period`, and its input stays as `loose: length / gravity` (`delete-leaves-loose.png`). Dragging the loose node's own output onto the hollow port wires it back: "Wired it in: it's part of the definition again." (#445). A loose `7` added on the canvas has an output, and wiring it into the place of a deleted `2` gives `7 · 3.14… · (length / gravity)` (#448). The palette for a new value is the side panel's, not a pop-up (#456). A loose hole says why `print` isn't offered: "print, die() and the like aren't offered." (#450).
- **Grouping** (#482). Right-click → Pick on two nodes, then "Group the 2 picked into one box" makes a named box (`group.png`). It undoes.
- **On a phone, + New program** opens the Run pane with its palette (#447) (`phone-new-program.png`).
- **Unit refusals mention units** (#468): "subtract doesn't fit here: units don't agree here: …". See L2 for which units it names.

## How to repeat

As in [QA-2026-10-24.md](QA-2026-10-24.md) and [QA-2026-10-26.md](QA-2026-10-26.md). New this time:

- **Picking with a mouse:** a plain click selects and Shift+click picks. Selection and picks are separate, so "Group the N picked" needs N picks. Right-click → Pick on each node is the reliable route in a script.
- **Steps in view:** count `.p-graph svg.canvas > g.world g.items > g` whose text has `print` and whose rect intersects the canvas.
