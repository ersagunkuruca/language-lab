# Writing a program in the editor, 2026-10-27

REVIEW-2026-10-26 §3 asked for a program written in the editor from a
description, by someone who doesn't know the answer in advance, with the
stumbles recorded. This is the first such session: the editor lane wrote
*count words* ("given a text, how often each word occurs") on the built
page, one gesture at a time, through a headless browser (each step a fresh
look at the page, as a person would see it). It's short on purpose: it
stops where the editor stops being able to say what was meant, and each
stop is a BACKLOG row.

## The session

1. **+ New program**, then **+ New definition** `count words` with one
   input `text`. Fine.
2. Looked for a way to split the text into words. Typed `words`: the only
   match is the page element `words : (Text) -> Html`. Typed `split`:
   `split(□, □) : (Text, Text) -> List Text`. Fine once found.
3. Looked for the map operations by what they do: `insert`, `lookup`,
   `get`: nothing. `key` finds `keys of`, `remove key`, `has key`, not
   `put` or `value at`. `Map` (the type) lists them all. **E136.**
4. Typed `fold`: the palette offers **fold text · List** (split `text` as a
   list) first and **fold □ · List** (on a value given next) second. Took
   the first by mistake, and `text` became `List a`. The two read
   differently, so that one is mine, not the editor's.
5. Selected `text` in `fold text`, **Replace with…**, typed
   `split(text, " ")`, Enter. Read and placed; `text` is `Text` again.
6. `nil →` **empty map**: typed, found, Enter. Fine.
7. `cons(head, tail) with tail′ →`: typed
   `put(tail′, head, first(() => value at(tail′, head), () => 0) + 1)`:
   "Nothing that fits matches". `first(() => 1, () => 0)` alone: the same.
   Typed text doesn't read a function written out. **E134.**
8. Typed `put(tail′, head, value at(tail′, head) + 1)`: read and placed,
   and `count words` became `(Text) -[Choice]-> Map Text a`: a word not
   yet in the map has no value, so the whole count fails. Right, but the
   fix, a default of 0, needs `value at(…)` inside `first(() => …, () => 0)`.
   Its menu has Replace, Clear, Delete, Change the function, but nothing
   that puts it *inside* something: retyping the whole arm is the only way.
   **E135.**

Noted, not filed: `entries(□)` (Map's field) and `entries of(□)` are both
offered for the same thing.

## After E134

With functions read from typed text (#PR), step 7 goes through as typed:
`put(tail′, head, first(() => value at(tail′, head), () => 0) + 1)`, and
`count words` is `(Text) -> Map Text a`. `main` takes
`print(show(count words("the cat and the hat")))` typed, and Run main
prints `map of([pair("and", 1), pair("cat", 1), pair("hat", 1), pair("the", 2)])`.
(How a map prints is the Language lane's.)
